# `dirs` 5 系は Win7 ターゲットのビルドで失敗する

| 項目 | 内容 |
| --- | --- |
| ID | 003 |
| Area | Windows 7 / 依存関係 |
| Updated | 2026-11-15 |

対象: `x86_64-win7-windows-msvc`、`dirs 5.0.1`。

## 試した理由

`dirs 5.0.1` → `dirs-sys 0.4.1` → `windows-sys 0.48.0` となり、`CoTaskMemFree` が `ole32.dll` にリンクされる。`combase.dll` 問題を避けられる可能性があった。

## 症状

リンク時に次のエラーになる。

```text
LINK : fatal error LNK1181: cannot open input file 'windows.0.48.5.lib'
```

## 原因

`windows-sys 0.48` が使う `windows-targets 0.48.5` の import lib が、Win7 ターゲットのリンク検索パスに追加されない。リンク行には `windows.0.52.0.lib` のパスだけがあり、0.48.5 側が見つからない。`build-std` と新しい Win7 ターゲットの組み合わせで、古い `windows-targets` が想定外になっている。

## 対応

この方向は採用せず、Windows では `dirs` 自体を使わない方針にした。
