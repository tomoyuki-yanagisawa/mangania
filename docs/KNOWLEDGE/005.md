# GitHub Actions の Node.js 20 非推奨と action バージョンの確認

| 項目 | 内容 |
| --- | --- |
| ID | 005 |
| Area | CI / GitHub Actions |
| Updated | 2026-11-16 |

## 症状

GitHub Actions で次の警告が出る。

```text
Node.js 20 is deprecated. The following actions target Node.js 20 but are
being forced to run on Node.js 24: actions/checkout@v4, actions/upload-artifact@v4.
```

## 原因

action の実体が `node20` を指定しているため。GitHub 側が Node.js 24 で実行するようになったので、警告が出る。動作は強制的に Node.js 24 で行われるが、action 側が Node.js 24 に未対応のままだと将来の変更で壊れる可能性がある。

## 対応

`node24` に対応したメジャーバージョンへ更新する。2026-11-16 時点の組み合わせは次の通り。

- `actions/checkout@v7`
- `actions/upload-artifact@v7`
- `actions/download-artifact@v8`

`actions/upload-artifact@v7` と `actions/download-artifact@v8` は Actions Runner 2.327.1 以上を要求する。GitHub ホステッドランナーは満たしているが、セルフホストランナーでは更新が必要。

## バージョンの確認方法

AI が生成した workflow は、作成時点のメジャーバージョンで古くなっていることがある。マージ前に実際の最新版と `runs.using` を確認する。

```sh
gh api repos/actions/checkout/releases/latest --jq .tag_name
gh api repos/actions/upload-artifact/releases/latest --jq .tag_name
gh api repos/actions/download-artifact/releases/latest --jq .tag_name
```

```sh
curl -fsSL https://raw.githubusercontent.com/actions/checkout/v7.0.1/action.yml | grep 'using:'
```

`using: node24` なら Node.js 24 対応。`actionlint` も workflow の構文・参照チェックに使う。

## 注意点

- `download-artifact@v8` はダイジェスト不一致が既定でエラーになる
- `upload-artifact@v7` は既定で zip のまま（`archive` を明示しない限り従来どおり）
- action のメジャーバージョンは定期的に更新する。Dependabot / Renovate の利用も検討する
- AI の記憶に頼らず、マージ時点の最新リリースを確認する
