# stable の通常ビルドは Windows 7 で起動しない

| 項目 | 内容 |
| --- | --- |
| ID | 001 |
| Area | Windows 7 / Rust |
| Updated | 2026-11-15 |

対象: Windows 7 SP1 x64、`x86_64-pc-windows-msvc`。

## 症状

`x86_64-pc-windows-msvc` でビルドした exe を Windows 7 で起動すると、`main` に入る前に落ちる。

```text
プロシージャエンドポイント ProcessPrng が
ダイナミックリンクライブラリ bcryptprimitives.dll から見つかりませんでした。
```

## 原因

Rust 1.78 以降の std が `ProcessPrng` を静的にインポートする。この関数は Windows 10 以降の `bcryptprimitives.dll` にしかなく、Windows 7 には存在しない。アプリコードではなく、標準ライブラリ側の依存。

## 対応

Tier 3 の `x86_64-win7-windows-msvc` を nightly + `build-std` でビルドする。

```sh
rustup toolchain install nightly
rustup component add rust-src --toolchain nightly
cargo +nightly build -Z build-std --target x86_64-win7-windows-msvc --release
```
