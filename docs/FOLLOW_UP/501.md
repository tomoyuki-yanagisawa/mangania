## やりたいこと

Windows の全画面表示でネイティブメニューバーが残らないようにする。全画面を解除したら元のメニューバーに戻す。

## スコープ

- やること: 全画面の切り替えに合わせて Win32 のメニューバーを外す／戻す
- やらないこと: Linux のメニューバー対応（ネイティブメニューは Windows / macOS のみ）

## 受け入れ条件

- [ ] 全画面中にメニューバーが見えない
- [ ] 全画面を解除するとメニューバーが元に戻る
- [ ] F11 / Esc / メニューからの全画面切り替えが壊れない

## 実装メモ

- 関連ファイル: `src/app.rs`、`src/menu.rs`
- 方針: `SetMenu(hwnd, NULL)` と `DrawMenuBar` を全画面の切り替え時に呼ぶ。解除時は元の HMENU を再設定する
- メニューのチェック状態は `MenuBar` 側で保持しているため、再設定後も維持する

## リスク / 依存

- メニューを外した状態でアクセラレータやショートカットが変わる可能性がある
- 全画面解除時の HMENU の再設定を忘れるとメニューが消えたままになる
