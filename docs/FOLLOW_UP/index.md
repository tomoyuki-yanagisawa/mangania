# Follow-up index

未実装の機能、改善、調査項目を管理します。1項目につき1ファイルを作成し、この index から辿れるようにします。

- テンプレート: [000.template.md](000.template.md)
- ファイル名: `NNN.md`（例: `001.md`）
- 新規項目はテンプレートをコピーして作成する。

## Status

| Status | 意味 |
| --- | --- |
| proposed | 起票しただけ |
| triaged | 内容・優先度・サイズを確認済み |
| ready | 実装可能な状態 |
| in-progress | 実装中 |
| blocked | 依存・判断待ち |
| done | 完了 |
| wontfix | 対応しない |

## Priority

| Priority | 意味 |
| --- | --- |
| P0 | すぐ対応が必要（破損・重大な不具合・リリース blocker） |
| P1 | 次に対応したい |
| P2 | 余裕があれば対応 |
| P3 | アイデア・将来候補 |
