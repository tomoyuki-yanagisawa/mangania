## やりたいこと

エクスプローラーから exe をダブルクリックしたときに、黒いコンソールウィンドウが出ないようにする。GUI と CLI の両方を壊さない方法を決める。

## スコープ

- やること: Windows の GUI 起動時にコンソールを出さない
- やらないこと: CLI 出力を GUI のログ画面に置き換えること

## 受け入れ条件

- [ ] ダブルクリック起動でコンソールウィンドウが出ない
- [ ] `--list` / `--check` / `--render-page` の出力が cmd から確認できる
- [ ] 起動エラーをユーザーが確認できる（コンソール、ログ、ダイアログのいずれか）

## 実装メモ

- 関連ファイル: `src/main.rs`
- 候補:
  - Windows のみ `#![windows_subsystem = "windows"]` を適用し、CLI 実行時に `AttachConsole(ATTACH_PARENT_PROCESS)` で親コンソールへ接続する
  - GUI 用と CLI 用のバイナリを分ける
- `AttachConsole` は起動元のコンソールがない場合に失敗するため、失敗時の出力先を決める

## 確認

- [ ] `cargo test`
- [ ] `cargo clippy --all-targets`
- [ ] 手動確認: Windows でダブルクリック起動と cmd からの CLI 実行
- [ ] 必要なドキュメント更新

## リスク / 依存

- `windows_subsystem = "windows"` を付けると `eprintln!` が見えなくなる
- CLI と GUI の両立方法によってはビルド成果物が増える

## メモ

- 現状はコンソールサブシステムのため、GUI 起動でもコンソールが出る
