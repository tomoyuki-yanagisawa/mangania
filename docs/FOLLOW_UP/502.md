## やりたいこと

エクスプローラーから exe をダブルクリックしたときに、黒いコンソールウィンドウが出ないようにする。GUI と CLI の両方を壊さない方法を決める。

## スコープ

- やること: Windows の GUI 起動時にコンソールを出さない
- やらないこと: CLI 出力を GUI のログ画面に置き換えること

## 受け入れ条件

- [ ] ダブルクリック起動でコンソールウィンドウが出ない
- [ ] `--list` / `--check` / `--render-page` の出力が cmd から確認できる
- [ ] 起動エラーをユーザーが確認できる（コンソール、ログ、ダイアログのいずれか）

## 実装メモ

- 関連ファイル: `src/main.rs`
- 採用:
  - Windows のみ `#![windows_subsystem = "windows"]` を適用する
  - 引数ありの起動では `AttachConsole(ATTACH_PARENT_PROCESS)` で親コンソールへ接続する
  - 既存の stdout / stderr / stdin が有効なら上書きしない（リダイレクトを維持）
  - `CONOUT$` / `CONIN$` を開いて `SetStdHandle` する
- `AttachConsole` は起動元のコンソールがない場合に失敗するが、その場合は GUI として動作する

## リスク / 依存

- `windows_subsystem = "windows"` を付けると `eprintln!` が見えなくなる
- CLI と GUI の両立方法によってはビルド成果物が増える

## メモ

- GUI サブシステム化と CLI 時の親コンソール接続を実装済み。Windows 実機での確認待ち
