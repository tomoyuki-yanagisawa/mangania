## やりたいこと

画面に合わせて画像を縮小するときのフィルタを設定できるようにする。漫画のスクリーントーンは細かい網点なので、縮小アルゴリズムによってはジャギーやモアレが出て画像が汚くなる。ユーザーが自分の環境や作品に合うフィルタを選べるようにする。

## スコープ

- やること: `config.toml` に縮小フィルタの設定を追加し、`view` の縮小処理に反映する
- やらないこと: 縮小処理そのものの非同期化や GPU 化

## 受け入れ条件

- [ ] `config.toml` でフィルタを指定できる
- [ ] 未指定時は現在の `Triangle` と同じ結果になる
- [ ] 不正な値は既定値にフォールバックする
- [ ] README / PREFERENCES に設定とトレードオフを記載する

## 実装メモ

- 関連ファイル: `src/view.rs`、`src/config.rs`、`src/app.rs`
- 現状は `view::blit_scaled` で `image::imageops::FilterType::Triangle` を固定使用している
- 候補: `nearest`、`triangle`、`catmull_rom`、`gaussian`、`lanczos3`
- `image::imageops::FilterType` は serde 非対応なので、設定用の enum を定義して変換する
- 大きな画像ではフィルタによって縮小時間が変わるため、必要ならログに縮小時間を出す（デバッグログは実装済み）

## リスク / 依存

- Lanczos 系はシャープになる一方でリンギングやモアレが増える場合がある
- 高品質なフィルタほど縮小に時間がかかる
- 縮小率が大きい場合は、一度で縮小するより段階的に縮小した方がきれいな場合がある（別項目で検討）

## メモ

- 既定は現状維持の `triangle` にする
- 漫画の網点は縮小率とフィルタの組み合わせで見え方が大きく変わる
