# MangaNia の既定値と好み

更新日: 2026-11-19

この文書は、製品の既定値、UX の好み、開発時の方針を記録します。
アーキテクチャは [DESIGN.md](DESIGN.md)、技術判断の理由は [DECISIONS.md](DECISIONS.md) を参照してください。

## 1. UI / UX

- UI の言語は日本語。
- 画像領域を最大化し、装飾的な UI は置かない。
- 設定は可能な限りメニューバーから変更し、TOML は永続データとして扱う。現在の対応範囲外の設定は TOML で変更する。
- エラー、読み込み状態、保存結果はタイトルバーと stderr に表示する。
- メニューは「ファイル」「移動」「表示」の最小構成にする。設定画面は作らず、表示モード・縮小フィルタ・拡大の可否は「表示」に置く。
- 「移動」には次のページ、前のページ、1ページ進む、1ページ戻る、先頭へ、末尾へを置く。
- 「表示」には縮小フィルタのサブメニューと「拡大を許可」のチェック項目を置く。
- 既定では画面より大きい画像を縮小し、小さい画像は画面いっぱいまで拡大する。「拡大を許可」を外すと縮小だけを行い、小さい画像は原寸で表示する。
- 縮小フィルタは `config.toml` でも指定でき、既定は `triangle`。
- 全画面はボーダーレス。`Enter` または `F11` で切り替え、`Esc` は全画面中なら解除、通常ウィンドウなら終了。
- Linux にはネイティブメニューを置かず、既定のキーバインドで操作する。
- 表示モードは単ページ表示 / 見開き表示 / 混合表示の3つ。既定は単ページ表示。
- 見開きは右→左。現在ページを右、次ページを左に置く。
- 見開きの組は先頭から `(1, 2)`, `(3, 4)`, ... とする。
- 混合表示はページの向きだけで決める。横長（正方形を含む）はウィンドウ全体の単ページ、縦長は右半分のセルに表示する。次ページも縦長なら左セルに並べ、それ以外は左セルを空白にする。
- 混合表示の表示サイズはページ自身の向きだけで決め、隣のページとの組み合わせでは再縮小しない。
- 中クリックでは開始ページを1つずらす（例: `(1, 2)` → `(2, 3)`）。その後の2ページ送りは同じ偶奇を保つ。
- 表紙の単独表示は行わない。
- 画像フォルダは選択したフォルダ直下の画像だけを読む。サブフォルダは無視し、自動で1段下がらない。サブフォルダを読むときは、そのフォルダを開き直す。
- 画像フォルダではシンボリックリンク、隠しファイル、対応外拡張子を除外する。
- ウィンドウサイズは既定で 1200×900。背景色は `#202020`。

## 2. 既定の設定

### config.toml

```toml
mode = "single"
export_dir = "~/Pictures/MangaNia"
export_name = "{book}_{page:03}"
prefetch = 2
cache_pages = 8
cache_mb = 128
scale_filter = "triangle"
debug = false
allow_upscale = true
```

- `mode = "single"`（単ページ表示）が既定。`spread`（見開き表示）と `mixed`（混合表示）を指定できる。以前の `spread = true/false` は使われない。
- `export_dir` の省略時は `~/Pictures/MangaNia`。
- `export_name` の省略時は `{book}_{page:03}`。
- `prefetch` の省略時は 2。単ページ表示ではページ数、見開き・混合表示では2ページ単位の段数。`--prefetch` が指定された場合は CLI を優先する。
- `cache_pages` の省略時は 8。`0` も 8 として扱う。各ページは表示サイズの画像を1枚だけ持つ。
- `cache_mb` の省略時は 128。`0` も 128 として扱う。`cache_pages` とどちらかに達した時点で破棄する。
- ディスクキャッシュは自動削除しない。メニューの「ファイル」>「キャッシュを削除」で手動削除する。
- `scale_filter` の省略時は `triangle`。`nearest` / `triangle` / `hamming` / `catmull_rom` / `mitchell` / `gaussian` / `lanczos3` を指定できる。不正な値は `triangle` に戻る。
- `debug` の省略時は `false`。`true` にすると `config.toml` と同じディレクトリの `debug.log` にログを出力する。
- `allow_upscale` の省略時は `true`。`false` にすると画面より小さい画像を拡大せず、縮小だけを行う。
- 同名ファイルは上書きする。
- 保存するのは現在ページのみで、元画像のバイト列をそのまま使う。

### keybindings.toml

```toml
[keys]
next = ["Right"]
prev = ["Left"]
first = ["Home"]
last = ["End"]
toggle_spread = ["v"]
single_page = []
spread_page = []
mixed_page = []
toggle_fullscreen = ["F11", "Enter"]
save_page = ["Ctrl+S", "Cmd+S"]
quit = ["Escape"]
```

- 修飾キーは `Ctrl` / `Shift` / `Alt` / `Super`（macOS の Cmd）。
- 文字キーは大文字小文字を区別しない。
- 修飾キーは完全一致で判定する。
- 1アクションに複数キーを指定できる。`[]` で無効化できる。

### mouse.toml

```toml
wheel_threshold = 50.0
double_click_ms = 500

[bindings]
next = ["left", "wheel_down"]
prev = ["right", "wheel_up"]
next_single = ["middle"]
save_page = ["double_left"]
```

- 既定の左シングルクリックは次のページ、右クリックは前のページ。
- ウィンドウが非アクティブなときのクリックは操作に使わない。Windows では OS のアクティブ化クリックを破棄する。
- 中クリックは1ページ送り。見開き・混合表示中は開始ページを1つずらす。
- 左ダブルクリックで表示中ページを保存する。
- ダブルクリックが割り当てられたボタンは、シングルクリック動作を `double_click_ms` だけ遅延させる。
- `wheel_threshold` はホイールで1ページ送りするために必要な移動量。
- ダブルクリックの判定距離は 10px。
- `double_click_ms` の既定は 500。
- 既存の `mouse.toml` の `double_click_ms` は自動で変更されない。既定値に揃えるには 500 に編集するか、ファイルを削除して再生成する。

## 3. ファイルとディレクトリ

設定ディレクトリ:

- macOS: `~/Library/Application Support/mangania/`
- Windows: `%APPDATA%\mangania\`
- Linux: `$XDG_CONFIG_HOME/mangania/`（未設定時は `~/.config/mangania/`）

| ファイル | 作成タイミング |
| --- | --- |
| `config.toml` | 初回起動時、表示モード・縮小フィルタ・拡大可否の変更時 |
| `keybindings.toml` | 初回起動時 |
| `mouse.toml` | 初回起動時 |

`config.toml` はコメント付きで生成され、そのまま編集できる。既定の保存先は `~/Pictures/MangaNia`。出力先がなければ作成する。

ZIP の展開済みページのディスクキャッシュ:

- Windows: `%LOCALAPPDATA%\mangania\cache`（未設定時は `%USERPROFILE%\AppData\Local\mangania\cache`、それも使えなければ OS の一時ディレクトリ）
- macOS: `~/Library/Caches/mangania`
- Linux: `$XDG_CACHE_HOME/mangania`（未設定時は `~/.cache/mangania`）

キャッシュには ZIP の展開済みページ画像が入る。不要になったらこのディレクトリを削除してよい。次にページを開くと再展開される。画像フォルダのページはキャッシュせず、元ファイルを直接読む。

## 4. パフォーマンスとリソース

- 先読み数の既定は 2。単ページ表示ではページ数、見開き・混合表示では2ページ単位の段数として扱う。`config.toml` の `prefetch` で変更できる。
- メモリキャッシュはページ数と容量の両方で制限する。既定は 8 ページ（1ページ1枚）と 128MiB で、`config.toml` の `cache_pages` と `cache_mb` で変更できる。どちらかに達した時点で破棄する。
- 保持するのはウィンドウに合わせて縮小した表示サイズ画像だけで、原寸のデコード結果はすぐ破棄する。
- 1つ前・現在・1つ先の表示に必要なページはキャッシュに残し、ソフト上限を超えても保持する。
- 上限を超えたときは、まず1つ前の表示より過去のページを遠い順に破棄する。次に1つ先の表示より未来のページを遠い順に破棄する。前後1表示と現在のページは破棄しない。同じ距離なら古い挿入を先に破棄する。
- 連続して戻る場合は、2表示以上前のページが破棄されているため再読み込みになる場合がある。
- ページ移動ではキャッシュを維持し、近いページの表示画像を再利用する。
- ZIP 読み出しとデコードは UI スレッドで行わない。デコード結果の縮小は UI スレッドで行う。
- ZIP エントリは専用ディレクトリのディスクキャッシュへストリーム展開し、そのファイルから直接デコードする。展開済みバイト列はメモリに保持しない。画像フォルダはキャッシュせず、元ファイルを直接デコードする。
- ディスクキャッシュは自動削除しない。不要になったらメニューから手動で削除する。
- ディスクキャッシュの作成・書き込み・読み出し・デコードに失敗した場合はページエラーにする。メモリ読み出しへのフォールバックはしない。
- 壊れたキャッシュファイルは削除してページエラーにし、次にそのページを読むときに ZIP から再展開する。画像フォルダの元ファイルは削除しない。
- ウィンドウサイズ、縮小フィルタ、表示モード、拡大の可否を変えるとキャッシュを捨て、現在ページと表示相手を再デコードする。ページの向きの記録は保持する。
- GPU 描画は必須にしない。

### 縮小フィルタのトレードオフ

- `nearest`: 最速だがジャギーが目立つ。拡大表示や確認用途向け。
- `triangle`: 既定。速度と画質のバランスが良く、通常の閲覧に向く。
- `hamming`: Triangle と同じくらい速く、輪郭が締まる。縮小向き。
- `catmull_rom`: Triangle より輪郭が締まる。線が強調される一方で過剰なシャープ感が出ることがある。
- `mitchell`: Catmull-Rom と同じくらいの速度で、より軟らかい。リンギングを抑えたいとき。
- `gaussian`: なめらかで軟らかい。細部はややぼける。
- `lanczos3`: 最もシャープ。スクリーントーンはくっきりするが、リンギング・モアレが出やすく縮小にも時間がかかる。

### 拡大と縮小

- 画面に収まらないページは、縦横比を保って縮小する。
- 既定では画面より小さいページを画面いっぱいまで拡大する。
- 「表示」>「拡大を許可」を外すと、小さいページは原寸のまま中央に表示する。縮小は常に行う。
- 拡大を許可しない場合も、表示サイズはページごとに1枚だけキャッシュする。

## 5. 対応形式と制約

- 対応形式: JPEG（ベースライン / プログレッシブ）、PNG、WebP、BMP。
- 対象外: RAR、7z、JPEG 2000、JPEG XL、AVIF、GIF。
- 読み方向は右→左固定。混合表示で横長ページを単独表示するのはページの向きによるもので、表紙だけを単独表示する設定はない。
- 設定画面、閲覧位置の保存、表紙の単独表示は未実装。表示モード・縮小フィルタ・拡大の可否は「表示」、ページ移動は「移動」メニューから変更できる。
- ディスクキャッシュに書き込めない環境ではページを表示できない。
- Windows 7 は実機未検証。Windows / Linux はコンパイル確認まで。

## 6. 開発の好み

- Rust 2024、単一 crate。
- 1ファイル・1モジュールの責務を小さく保つ。目安は 600 行以下。
- 純粋なロジックは UI から分離し、単体テストを書く。
- 不必要な crate は追加しない。追加時は理由を DECISIONS.md に記録する。
- コード内コメントは英語、ユーザー向け文書と UI 文言は日本語。
- 変更は Conventional Commits に従い、英語のコミットメッセージにする。
- 変更後は `cargo fmt`、`cargo test`、`cargo clippy --all-targets` を通す。
